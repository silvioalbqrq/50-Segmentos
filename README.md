# Reforma Tributária Setorial — 50+ Segmentos

Site estático com o conteúdo completo do e-book *Reforma Tributária Setorial* (Bruno Viana Macedo / Academia Elite Fiscal), baseado na **LC 214/2025** e **LC 227/2026**.

## Paleta e tipografia

- Fundo verde-escuro (`#0a1f14`)
- Destaque dourado (`#d4a84b`)
- Títulos: Cormorant Garamond
- Texto: Inter

## Publicar no GitHub Pages

1. Faça push deste conteúdo para `silvioalbqrq/50-Segmentos`
2. Settings → Pages → branch `main` / root
3. Site: https://silvioalbqrq.github.io/50-Segmentos/

## Proteção

`js/protect.js` dificulta inspeção de código (F12, view-source, clique direito). O texto visível continua selecionável e copiável.
